# Facial-expression fidelity

Apply this to every character on all future and revised DB OCG cards, including Combat, Event, Setup, Drill, Personality, Hi-Tech and Mastery. Compare the original scan with the finished modern card, not merely the generated illustration or its prompt.

Check each visible face for: closed versus open mouth; teeth/tongue visibility; smiling, smirking, grimacing or shouting; which mouth corner is raised; eye openness and gaze; eyebrow angle and tension. Preserve the source expression while retaining the approved cell shading, linework, palette, pose and crop. Do not replace a distinctive expression with a generic stern face.

Blue Style Mastery, Trunks Saga #149, is the corrective example: Piccolo has a narrow asymmetrical tooth-showing smirk with the viewer-right corner raised. The former modern version incorrectly had a straight closed mouth. The user's original reference is `1837.png` (Library `libfile_65d23b31a22881919442396ae4afdef7`).

For expression-only corrections, use imagegen for the isolated face/mouth artwork. Composite only the smallest necessary patch through a verified mask into the retained artwork and native master. Keep all other character pixels, frame, text, icons and game data unchanged; save losslessly and require zero decoded-pixel differences outside the allowed footprint. Preserve the existing display and download dimensions. Do not regenerate the complete card or re-encode unrelated pixels lossily.

Review at normal card size and enlarged. A tiny, obscured or low-resolution face is `unresolved`, not a pass. Mark cards without visible facial features `not applicable`. Keep explicit approved artwork exceptions, including Frieza #125's rear-facing Goku. Compare Hi-Tech foreground expressions; decorative silhouettes are not substitutes for the foreground face.

For older-card audits, record each card ID, exact original reference, inspected finished version, verdict and specific mismatch. Separate initial contact-sheet screening from enlarged verification. Do not claim all existing cards were checked when only a subset was inspected. Correct only confirmed expression mismatches within the authorized scope; report other pose or composition differences separately.
