# Edo SZ

Edo SZ by Vic Fieger, copyright 2008. The author's DaFont listing labels this face “100% Free”:
https://www.dafont.com/edo-sz.font

Downloaded on 2026-10-29 from the listing's download link:
https://dl.dafont.com/dl/?f=edo_sz

The original `edosz.ttf` was converted to WOFF2 without changing its outlines,
character set or font metadata. This face is also credited in the site's retained
`public/assets/arena-banner-edo.svg` source. It supplies live, accessible lettering
for Version 2's Start New Topic and Reply to Topic buttons. The current charcoal
banner is a raster image, so the font is a brush-style match rather than extracted
lettering from that image.
