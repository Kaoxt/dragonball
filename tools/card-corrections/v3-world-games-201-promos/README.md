# World Games 201, promos and previews publication

The 18 supplied cards add Videl 201, P1–P10 and PR1–PR7 to World Games Saga.
Supplied sources, artwork, reference scans, audits and exports are preserved
exactly. `package/` retains preparation evidence; `publication.json` records
the additive repository integration and baseline. Four explicit Arena charts
serve saved deck snapshots, including Supreme Kai's eleven Z stages plus zero.
The existing corrected Hi-Tech masks also match Videl. New permanent deck IDs
are appended. Earlier audits retain their original membership through
`tests/helpers/pre-world-games-promos.js`.

The package README's Face Off note refers to the Combat cards prohibited by
its rules becoming Events. Face Off itself remains Setup, matching its
original Non-Combat reference, supplied native card and catalog data.
