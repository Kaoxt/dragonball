SOURCE / EXPORT POLICY
Canonical SVGs use the retained 2x artwork raster; -web-1x.svg companions use
the corresponding native 1x raster. Existing vector UI and original art groups
remain in each SVG. Do not regenerate or repaint characters, remove repair
layers, or globally rerender the supplied WebPs before publication. Supplied
exports preserve the published UI raster exactly. The source files depend on
existing repository artwork; unchanged dependencies are hash-guarded.

Publication is not performed by this package. It contains reviewed assets,
native sources, historical source snapshots, checks and a guarded installer.
The publishing agent must integrate this revision with the repository's
existing historical audit chain, run current required checks, and deploy only
under the user's publishing instruction. Prior audits remain immutable.
