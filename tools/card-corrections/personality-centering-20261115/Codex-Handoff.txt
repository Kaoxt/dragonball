Prepared November 15, 2026. This package has not been published.

SCOPE

Historical native snapshots and review evidence are in the new append-only
tools/card-corrections/personality-centering-20261115 directory.
This is a patch for the existing Kaoxt/dragonball repository, not a standalone
copy of the entire card-art archive. Unchanged dependencies must be present.

APPLY TO AN ISOLATED CURRENT CHECKOUT
1. Read the current repository AGENTS.md and relevant card audit instructions.
2. Run from this extracted package:
     python3 apply_fix.py /absolute/path/to/dragonball
   This is a dry-run. All payload hashes, existing asset/native hashes,
   unchanged dependencies, card content and 90 catalog URLs are checked.
3. If the dry-run passes, install the prepared assets:
     python3 apply_fix.py /absolute/path/to/dragonball --apply
   The installer only changes listed files and catalog image/download URLs.
   It preserves unrelated catalog changes. It never commits, pushes or deploys.
4. If a conflict is reported, do not force or discard the newer work. Compare
   the manifest baseline, current card, and supplied revision, then merge that
   card deliberately. Do not overwrite a newer expression or rules correction.
